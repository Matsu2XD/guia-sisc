> Guia de orientações sobre o Serviço de Convivência e Fortalecimento de Vínculos (SCFV) e o passo a passo de utilização do SISC, com todas as capturas de tela do sistema.

---

## Sobre

O **SISC — Sistema de Informações do Serviço de Convivência e Fortalecimento de Vínculos** é a ferramenta de gestão da Rede SUAS destinada ao registro e acompanhamento do SCFV. Este guia reúne:

- Conteúdo **conceitual** do SCFV: o que é, finalidade, eixos norteadores, público-alvo, grupos e equipe técnica;
- **Registro e financiamento**: como o SCFV é registrado no SISC e financiado via cofinanciamento federal (PBV);
- **Legislação e normativas federais** do SCFV;
- **Manual do SISC** com tutoriais de todos os menus (Grupos, Usuários e Relatórios), ilustrados com todas as capturas de tela do sistema;
- **Anexos**: checklist, regras de ouro, base normativa e dúvidas recorrentes.

## Executar localmente

```bash
# Instalar dependências
npm install

# Modo desenvolvimento
npm run dev

# Build de produção
npm run build

# Preview do build
npm run preview
```
